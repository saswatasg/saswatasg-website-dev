# Adda: shared UX, a personal journal

Adda uses the same Header component as Workbench. The shell is a fixed-height rectangular floating bar (68px desktop, 64px below 1000px), with a home icon, route-specific navigation, an integrated world switch, and a mobile menu. Active routes use muted gold; hover uses sage. Escape dismisses the mobile menu and returns focus to its trigger. The split entrance remains unchanged.

Inner pages use AddaPageHeader: breadcrumb, one H1, a short introduction, and a topic-specific illustration. Writing, cinema, photography and About end with the same conversation invitation. Gallery details keep their explicit return link and keyboard-accessible image viewer. Contact uses the same message form and iframe booking dialog as Workbench.

Reading widths match Workbench: 1200px outer / 1152px content, 24px desktop gutters, 20px mobile gutters. Major panels have square corners, 2px outlines and 4px hard shadows. Actions use 4px corners, 44px minimum targets and 2px shadows. A compact anchor navigation helps visitors explore the homepage without repeated keyword labels.

Adda retains its Bengali wordmark, kurta portrait, Kolkata skyline, folk motifs, serif editorial headings and personal content. Palette: forest #07594f, cream #fff3d8, gold #efcf83, sage #dce6d5, clay #eed6c2. Graphics remain clearly labeled where original photographs or manuscript titles have not yet been supplied.

Both worlds now use the same route entrance timing and respect reduced-motion preferences. The separate bottom world-switch dock has been removed from Adda; switching is consistently available in the header.
